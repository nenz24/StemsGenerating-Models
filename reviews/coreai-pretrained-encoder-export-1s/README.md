# Pretrained VAE encoder: one-second Linux export

The complete pinned VAE checkpoint was reused from the local cache and its
337,431,388-byte size and full publisher SHA-256 verified. Every `encoder.*`
tensor was loaded strictly into Diffusers 0.37.0 OobleckEncoder and converted
to Float32. No decoder or diffusion-generator tensors were loaded.

The exported wrapper returns the first half of the encoder parameters: the
posterior mean, equivalent to `OobleckDiagonalGaussianDistribution(...).mode()`.
It does not sample the stochastic posterior. The input is a fixed one-second
48 kHz stereo multitone with a sine-squared envelope, generated in Float64 then
stored as Float32. It is synthetic audio, not the user's recording.

PyTorch produced a finite [1, 64, 25] reference from [1, 2, 48000] audio.
Removing weight-normalization reparameterization left that reference exactly
unchanged. Export through coreai-torch 0.4.3/coreai-core 1.0.0b3 produced a
native `encoder.aimodel`, with the native hash generated by the exporter.
An independent `--component encoder --verify-only` pass rechecked all prepared
file hashes and binary sizes. Both existing decoder bundles also passed
integrity verification after adding encoder support.

A fresh 0.2 s decoder export through the shared preparation code also succeeded;
both its latent input and reference audio SHA-256 matched the preserved decoder
baseline exactly. Eleven integrity/setup tests passed, covering the encoder mean
contract and preservation/reuse of all separate bundles. The Xcode project parsed
successfully and its existing resource folder covers the new encoder package.

[reference.json](reference.json) records the Linux artifact hashes and reference
statistics. Checkpoint and exported weights stay in ignored local directories;
they are not committed, and Mac exports need not be byte-identical to Linux.
The app's updated Swift profile has not been compiled against the Apple SDK
here. Encoder device parity, memory and timings are pending. This evidence
does not establish reconstruction quality, conditioning behavior or full
instrument generation. Follow the [Mac and iPhone steps](../../docs/coreai-pretrained-encoder.md).
